EXPERIMENT C -- MONOTONICITY ADDENDUM
========================================================

Rule: within a base graph the degree sequence is FIXED; the
only thing that changes is the wiring. If the plateau rises
monotonically as community structure strengthens (mu falls),
that ordering has probability 1/6 under the null for three
levels (1/3 if either direction is allowed).

  base 0  mu=[0.75, 0.45, 0.15]  plateau=[0.00705, 0.01308, 0.01670]   INCREASING
  base 1  mu=[0.75, 0.45]  plateau=[0.00860, 0.01376]   INCREASING
  base 2  mu=[0.75, 0.45, 0.15]  plateau=[0.00645, 0.00918, 0.05277]   INCREASING

  monotone increasing in 3/3 base graphs
  monotone decreasing in 0/3 base graphs

  under H0: P(all increasing by chance) = (1/6)^3 = 0.00463
            P(all monotone by chance)   = (1/3)^3 = 0.03704

CAVEAT that must travel with every number in experiment C:
  all runs stopped at a MATCHED HORIZON of 95 steps
  (status = horizon_reached, NOT saturated). The comparison
  therefore shows that community structure slows and raises
  the residual at equal flow time; it does not prove the
  asymptotic plateau is higher. Synthetic values wouldkeep
  falling if run longer, so the remaining gap to real
  networks (which ARE saturated) is a LOWER bound on the
  true gap.
